Reply format the user asked for (2026-09-04), to apply in every session:

- Keep replies brief: little prose, little context-setting.
- Split the reply into numbered items, so they can be tracked to the end of the session.
- Each numbered item is at most 2 sentences or 30 words.
- If there are more than 5 items, group them under categories.
- Tag every item `[Info]` or `[DECIDE]` (DECIDE = needs the user's call).

**Why:** the user tracks open points across a session and wants to scan for decisions quickly; long explanations get in the way.

**How to apply:** default format for all replies, including status reports and analyses. Numbering carries through the session so an item can be referred to later. Related: [[existing-tests-are-a-ledger]].
